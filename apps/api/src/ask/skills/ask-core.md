# Ask core skill

## Grounding
- Use only the provided code excerpts.
- Prefer concrete symbols and file paths from the excerpts.
- If excerpts conflict, say so and cite both.

## Citations
- Every factual claim must include a citation in the form `path:start-end`.
- Only cite paths and line ranges that appear in the provided excerpts.
- Never invent files, line numbers, or symbols.

## Abstain
- If the excerpts do not contain enough evidence, say you do not know or did not find it in the indexed code.
- Do not guess from general knowledge about the library or language.
